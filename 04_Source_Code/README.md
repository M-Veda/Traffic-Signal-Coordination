# Source code - Intelligent Traffic Signal Coordination Using Multi-Agent RL

Nine tabular Q-learning agents control the signals of a simulated 3x3 road grid and are compared with Random,
Fixed-time and Longest-queue-first control on identical traffic. See the root `README.md` for the full project description and results.

**Simulator note:** SUMO and CityFlow were *not* used. The project uses a custom lightweight Python queue-based simulator
(`traffic_env.py`) so that it installs with `pip` only and needs no API keys. Absolute numbers (seconds, vehicles) are properties of this simulator, not of real roads.

## Modules
| File | Purpose |
|---|---|
| `config.py` | all constants (network, demand, reward weights, Q-learning settings, seeds) |
| `traffic_env.py` | simulator + demand generator (identical demand for every controller) |
| `agents.py` | Fixed-time, Random, Longest-queue-first, IQL and cooperative IQL agents |
| `train.py` | trains IQL and Coop-IQL (5 runs each, 1000 episodes) |
| `evaluate.py` | evaluates all controllers on 5 scenarios x 10 unseen seeds |
| `make_results.py` | charts + tables from the raw results |
| `visualize.py` | animation (GIF) of vehicles and traffic lights |
| `make_architecture.py`, `build_documents.py`, `build_presentation.py` | diagrams, PDFs, PowerPoint |
| `tests/test_env.py` | 5 unit tests |
| `run_all.py` | whole pipeline in one command |

## Setup (Windows 10/11, PowerShell or Command Prompt)
Requires Python 3.10+ (developed with Python 3.12 on Linux; the Windows commands below were **not** executed on a Windows machine).
```
cd Traffic-Signal-Coordination\04_Source_Code
python -m venv .venv
.venv\Scripts\activate
pip install -r ..\requirements.txt
```
(PowerShell: if activation is blocked run `Set-ExecutionPolicy -Scope Process Bypass` first.)

## Run
```
python -m unittest discover -s tests         :: 5 unit tests, a few seconds
python run_all.py --quick                    :: smoke test (about 1 minute), writes ..\05_Experimental_Results_quick
python run_all.py                            :: full experiment (about 10-15 min on one CPU core), overwrites ..\05_Experimental_Results
python build_documents.py                    :: report + problem-formulation PDFs (needs ..\05_Experimental_Results and its iteration1 folder)
python build_presentation.py                 :: 5-slide pptx
python visualize.py --controller coop --scenario asym --start 700 --duration 100
```
Controllers for `visualize.py`: `fixed`, `random`, `lqf`, `iql`, `coop`; scenarios: `low`, `medium`, `high`, `asym`, `peak`.

## Reproducibility
All randomness is seeded (training seeds 0-4, demand seeds 0-999 for training, 1000-1009 for testing). Re-running
the full pipeline should reproduce the reported numbers on the same library versions; small differences are possible
across NumPy versions. `05_Experimental_Results/iteration1_v1_400ep` holds the archived first design (400 episodes, neighbour-queue information)
produced with an earlier version of `agents.py`; it is kept for transparency and is not regenerated by `run_all.py`.
